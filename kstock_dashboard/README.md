# 한국 증시 단기 대시보드 (1단계)

관심종목 여러 개의 1~5거래일 방향을 점수(-100 ~ +100)로 추정하는 Streamlit 대시보드입니다.
전체 설계(점수 모델, 미국 매크로 이벤트, DART 공시, 수출입 데이터)는 [docs/DESIGN.md](docs/DESIGN.md)를 참고하세요.

> 분석 보조 도구이며 투자 권유가 아닙니다. 가중치와 기준값은 백테스트 전의 **출발값**입니다.

## 실행

**Windows:** `Run_program.bat`을 더블클릭하세요. 처음 실행할 때는 가상환경(`.venv`)을 만들고 패키지를 설치하느라 몇 분 걸리고, 다음부터는 바로 실행됩니다. 패키지를 다시 설치하려면 `.venv\installed.txt`를 지우세요. (Python 3.10 이상 필요)

**직접 실행:**

```bash
cd kstock_dashboard
pip install -r requirements.txt
streamlit run app.py
```

- 사이드바의 **데이터** 설정에서 `자동`(실데이터 실패 시 샘플) / `실데이터만` / `샘플`을 고를 수 있습니다.
- 사이드바의 **⭐ 관심종목**에서 이름이나 코드로 종목을 검색해 최대 20개까지 추가합니다. 관심종목은 `watchlist.json`에 저장되어 다음 실행 때도 유지됩니다.
  - 검색 목록은 pykrx로 KOSPI·KOSDAQ 전체 종목을 받아 하루 동안 캐시합니다. 받아오지 못하면 내장된 주요 종목(`data/stocks.csv`)만 검색됩니다. 목록에 없는 종목은 "종목 코드 직접 추가"로 넣을 수 있습니다.
- 사이드바의 **데이터 새로고침**에서 `🔄 지금 새로고침` 버튼으로 즉시 갱신하거나, 자동 새로고침 주기(끄기/1/5/10/30분)를 고를 수 있습니다. 새로고침하지 않으면 데이터는 10분간 캐시됩니다. 사이드바가 안 보이면 화면 왼쪽 위의 `>` 버튼을 누르세요.
- 샘플(합성) 데이터를 쓰면 화면 상단에 경고가 표시됩니다. 이 데이터는 화면 확인용일 뿐 실제 시장과 관계가 없습니다.

테스트:

```bash
python -m pytest -q
```

## 화면 구성

| 탭 | 내용 |
|---|---|
| 상단 | KOSPI·KOSDAQ·원/달러·나스닥·SOX·VIX, 다음 1등급 시장 이벤트까지 남은 날(D-day) |
| ⭐ 관심종목 | 종목별 현재가, 등락률, 1일·5일 점수와 판단, 신뢰도, 관련 이벤트를 한 표로 비교. 행을 클릭하면 종목 상세 탭에서 그 종목이 선택됨 |
| 🎯 종목 상세 | 업종 프로필 선택, 1일·5일 점수와 영역별 기여도, 이벤트 필터 내역, E 영역 수동 입력, 세부 지표, 캔들·수급 차트 |
| 📅 이벤트 달력 | 관심종목에 해당하는 이벤트만 표시(시장 전체 + 종목·업종 이벤트), 종목별 점수 배수 |
| 🌐 시장 지표 | KOSPI 캔들, 글로벌 지표 표 |
| 🧪 백테스트 | 종목을 골라 점수 구간별 평균 수익률과 상승 확률, IC(Spearman) |

## 업종 프로필

A 영역(글로벌 연관 지표)은 종목의 업종에 맞는 해외 지표의 전일 수익률을 씁니다. 업종별 지표와 가중치는 `config/model.yaml`의 `sector_profiles`에서 바꿀 수 있습니다.

| 프로필 | A 영역 해외 지표 |
|---|---|
| 반도체 | SOX, 마이크론, 엔비디아, EWY |
| 2차전지 | 테슬라, 리튬·배터리 ETF(LIT), 앨버말, EWY |
| 자동차 | GM, 도요타, 포드, EWY |
| 바이오·제약 | XBI, IBB, EWY |
| 인터넷·게임·엔터 | 나스닥, 메타, 알파벳, EWY |
| 금융 | XLF, KBE, EWY |
| 조선·방산·전력기기 | XLI, ITA, GE 버노바, EWY |
| 정유·화학·소재 | WTI, XLE, XLB, EWY |
| 소비재·화장품·식품 | XLP, KWEB, EWY |
| 기타 (시장 전체) | S&P 500, 나스닥, EWY |

내장 주요 종목은 업종이 미리 지정되어 있습니다. 그 밖의 종목은 "기타"로 시작하며, 종목 상세 탭에서 업종 프로필을 바꾸면 저장됩니다.

```

├── data/events.yaml     # 이벤트 일정, KRX 휴장일                   ← 여기서 관리

│   ├── scoring.py       # 점수 모델, 업종 프로필 적용
│   ├── stocks.py        # 종목 목록·검색, 관심종목 저장
│   ├── calendar.py      # 한국시간 변환, 한국장 반영일, 옵션만기 생성, 이벤트 위험 필터

```

## 운영 시 알아 둘 점

- **시점 정렬:** 거래일 T를 예측할 때는 날짜가 T보다 앞선 데이터만 씁니다. 장이 끝나기 전에는 오늘을, 장이 끝난 뒤에는 다음 거래일을 예측합니다. 공매도 잔고는 공개가 T+2일이라 2거래일 늦춰서 씁니다.
- **E 영역(업황·이벤트)**은 무료로 자동 수집하기 어려워 사이드바에서 직접 입력합니다. 입력하지 않으면 결측으로 처리되고, 그 가중치는 나머지 영역에 재배분됩니다.
- **결측 가중치가 20%를 넘으면 판단을 보류합니다.** 예를 들어 pykrx 수집이 실패하면 수급 영역이 비어서 5일 예측이 보류될 수 있습니다.
- **일정 파일**(`data/events.yaml`)에서 `status: estimated`인 항목은 예상일입니다. 공식 캘린더로 확인한 뒤 `confirmed`로 바꾸세요. KRX 휴장일도 매년 공지로 확인해야 합니다.
- **백테스트**에는 A~D 영역만 사용합니다. 수익률은 실제로 매매할 수 있는 **T일 시가 → T+h-1일 종가** 기준이며, 거래비용은 반영하지 않습니다.
- **데이터 출처의 한계:** pykrx는 KRX 웹사이트를 수집하는 방식이라 사이트가 바뀌면 동작하지 않을 수 있습니다. yfinance도 비공식 API입니다.
