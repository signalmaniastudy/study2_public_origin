# 한국 증시 단기 대시보드 (1단계)

SK하이닉스를 대상으로 1~5거래일 방향을 점수(-100 ~ +100)로 추정하는 Streamlit 대시보드입니다.
전체 설계(점수 모델, 미국 매크로 이벤트, DART 공시, 수출입 데이터)는 [docs/DESIGN.md](docs/DESIGN.md)를 참고하세요.

> 분석 보조 도구이며 투자 권유가 아닙니다. 가중치와 기준값은 백테스트 전의 **출발값**입니다.

## 실행

**Windows:** `Run_program.bat`을 더블클릭하세요. 처음 실행할 때는 가상환경(`.venv`)을 만들고 패키지를 설치하느라 몇 분 걸리고, 다음부터는 바로 실행됩니다. 패키지를 다시 설치하려면 `.venv\installed.txt`를 지우세요. (Python 3.10 이상 필요)

**직접 실행:**

```bash
cd kstock_dashboard
pip install -r requirements.txt
streamlit run app.py
```

- 사이드바의 **데이터** 설정에서 `자동`(실데이터 실패 시 샘플) / `실데이터만` / `샘플`을 고를 수 있습니다.
- 샘플(합성) 데이터를 쓰면 화면 상단에 경고가 표시됩니다. 이 데이터는 화면 확인용일 뿐 실제 시장과 관계가 없습니다.

테스트:

```bash
python -m pytest -q
```

## 화면 구성

| 탭 | 내용 |
|---|---|
| 상단 | KOSPI·KOSDAQ·SK하이닉스·원/달러·SOX·VIX, 다음 1등급 이벤트까지 남은 날(D-day) |
| 🎯 SK하이닉스 점수 | 1일·5일 예측 점수, 판단, 신뢰도, 영역별 기여도, 이벤트 필터 적용 내역, 세부 지표 |
| 📅 이벤트 달력 | 2주 보기(한국장에 반영되는 거래일 기준) / 월간 목록, 분류·등급 필터, 현재 점수 배수 |
| 🌐 시장 지표 | SK하이닉스 캔들과 5일·20일선, 외국인·기관 순매수, 글로벌 지표 표 |
| 🧪 백테스트 | 점수 구간별 평균 수익률과 상승 확률, IC(Spearman) |

## 운영 시 알아 둘 점

- **시점 정렬:** 거래일 T를 예측할 때는 날짜가 T보다 앞선 데이터만 씁니다. 장이 끝나기 전에는 오늘을, 장이 끝난 뒤에는 다음 거래일을 예측합니다. 공매도 잔고는 공개가 T+2일이라 2거래일 늦춰서 씁니다.
- **E 영역(업황·이벤트)**은 무료로 자동 수집하기 어려워 사이드바에서 직접 입력합니다. 입력하지 않으면 결측으로 처리되고, 그 가중치는 나머지 영역에 재배분됩니다.
- **결측 가중치가 20%를 넘으면 판단을 보류합니다.** 예를 들어 pykrx 수집이 실패하면 수급 영역이 비어서 5일 예측이 보류될 수 있습니다.
- **일정 파일**(`data/events.yaml`)에서 `status: estimated`인 항목은 예상일입니다. 공식 캘린더로 확인한 뒤 `confirmed`로 바꾸세요. KRX 휴장일도 매년 공지로 확인해야 합니다.
- **백테스트**에는 A~D 영역만 사용합니다. 수익률은 실제로 매매할 수 있는 **T일 시가 → T+h-1일 종가** 기준이며, 거래비용은 반영하지 않습니다.
- **데이터 출처의 한계:** pykrx는 KRX 웹사이트를 수집하는 방식이라 사이트가 바뀌면 동작하지 않을 수 있습니다. yfinance도 비공식 API입니다.
