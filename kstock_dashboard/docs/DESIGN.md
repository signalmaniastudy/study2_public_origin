# 한국 주식 단기 분석 시스템 설계

대상: 관심종목 여러 개 (예시: SK하이닉스) · 투자 방식: 단기매매 · 예측 기간: 1~5거래일 · 결과: 점수(-100 ~ +100)

| 모듈 | 내용 | 구현 단계 |
|---|---|---|
| 1. 지표 대시보드 | 국내외 지수, 환율·금리, 원자재, 수급 | **1단계 (구현됨)** |
| 2. 단기 방향 점수 모델 | A~E 영역 가중합, 판단 구간, 필터 | **1단계 (구현됨)** |
| 3. 미국 매크로 이벤트 | 발표 전 위험 필터 + 발표 후 서프라이즈(F 영역) | 필터는 1단계, F 영역은 3단계 |
| 4. 이벤트 달력 | 등급별 일정, 한국장 반영일, D-day | **1단계 (구현됨)** |
| 5. DART 공시 분석 | 규칙 분류 → 강도 계산 → LLM 해석 | 2~3단계 |
| 6. 수출입 데이터 분석 | HS 코드·지역 기반 종목 수출 트래커 | 2단계 |

> 모든 가중치와 기준값은 백테스트 전의 출발값입니다. 이 시스템은 분석 보조 도구이며 투자 권유가 아닙니다.

## 2. 단기 방향 점수 모델

```
최종 점수 = 100 × Σ (영역 가중치 × 영역 점수)          세부 지표 점수: -1 ~ +1
```
매일 08:30(장 시작 전) 계산합니다. 설정 파일은 `config/model.yaml`입니다.
종목마다 업종 프로필(`sector_profiles`: 반도체, 2차전지, 자동차, 바이오, 인터넷, 금융, 조선·방산·전력, 정유·화학, 소비재, 기타)을 적용해 A 영역 지표를 바꿉니다. 이벤트는 시장 전체, 특정 종목(`ticker`), 특정 업종(`sectors`)으로 구분해 해당 종목에만 필터를 적용합니다.

| 영역 | 1일 | 5일 | 세부 지표 (영역 안 비중) |
|---|---|---|---|
| A. 글로벌 연관 지표 | 30% | 20% | 업종 프로필의 해외 지표 전일 수익률. 반도체 예: SOX(35%), 마이크론(25%), 엔비디아(20%), EWY(20%) |
| B. 수급 | 20% | 25% | 외국인 5일 순매수 비율(40%), 기관(20%), 외국인 연속 매매일수(20%), 공매도 비중 변화(20%) |
| C. 가격·기술적 | 25% | 25% | 추세(30%), RSI(25%), 거래량×방향(25%), 3일 과열·반전(20%) |
| D. 매크로·환율 | 15% | 15% | 원/달러(35%), 미 10년물(25%), VIX(20%), KOSPI 외국인(20%) |
| E. 업황·이벤트 | 10% | 15% | 업황 지표(35%, 반도체는 DRAM 현물가), 실적 전망 변화(30%), 수출 서프라이즈(15%), 뉴스(20%) |

**판단 구간:** +50 이상 강한 상승 / +20~+50 상승 우위 / -20~+20 중립 / -50~-20 하락 우위 / -50 이하 강한 하락

**필터:**
- 이벤트 배수: 1일 예측은 1등급 ×0.5, 2등급 ×0.85 / 5일 예측은 1등급 ×0.7, 2등급 ×0.85
- 1등급 이벤트가 2건 이상이면 신뢰도 낮음, 관망 권고
- VIX 또는 VKOSPI가 30을 넘으면 판단 구간을 ×1.5로 넓힘
- 영역 간 신호가 충돌하면(±0.6) 신뢰도 낮음
- 결측 가중치가 20%를 넘으면 판단 보류

**매매 규칙 예시 (검증용):** +30 이상 진입, 손절 1.5×ATR(14), 5거래일 경과 또는 점수 0 미만 시 청산

**검증:**
- 점수 구간별 평균 수익률과 상승 확률
- Spearman IC (0.05 이상이면 의미 있는 수준)
- 기간을 옮겨 가며 검증(walk-forward)
- 비교 대상: 그냥 보유했을 때, 전날 방향이 이어진다고 가정한 단순 예측
- 수익률은 T일 시가 기준으로 계산 (전일 종가 기준이면 시가 갭까지 성과로 잡혀 과대평가됨)

**한계:**
- 미래 정보가 섞이는 실수(수급 확정치와 공매도 데이터의 공개 시점)
- 시장 국면이 바뀌면 지표 효과도 바뀜
- 1~5일 적중률은 52~57%면 양호한 편
- 거래비용은 왕복 약 0.2~0.3%
- 돌발 이벤트는 반영되지 않음
- SOX·MU·NVDA가 강하게 연동되어 같은 신호를 두 번 셀 수 있음

## 3. 미국 매크로 이벤트

| 등급 | 지표 |
|---|---|
| 1등급 | FOMC, CPI·근원 CPI, 고용보고서 |
| 2등급 | PPI, PCE, ISM PMI, 소매판매, GDP |
| 3등급 | 주간 신규 실업수당 청구 |

- **발표 시각(한국 시간):**
  - CPI·PPI·고용지표: 21:30 (미국 서머타임 기간), 그 외 기간 22:30
  - FOMC: 다음 날 03:00 (서머타임 기간), 그 외 기간 04:00
- **발표 전 위험 필터** (구현됨): 위 2절의 이벤트 배수
- **발표 후 서프라이즈 (F 영역, 3단계):**
  - 계산: `z = (실제치 − 예상치) / 과거 서프라이즈 표준편차`. 물가 지표는 `-clip(z/2)`
  - 권장 방식: 발표 당일 **미 2년물 금리 변화**를 대리 지표로 사용. 점수 = `-clip(Δbp/10)`
  - FOMC: 금리 결정과 FedWatch 기대치의 차이, 점도표 변화, 2년물 반응
  - 효과 감소: 발표 t일 후 `0.7^t`를 곱함. 1일 예측에서는 A·D 영역과 같은 신호를 두 번 세지 않도록 0.5배
  - 가중치: 최근 5일 안에 이벤트가 있으면 F=15%로 활성화하고 나머지 영역을 비례 축소
- **데이터:** BLS·BEA·FRED(실제치), 연준 캘린더, CME FedWatch, Investing.com(예상치)

## 4. 이벤트 달력

- **분류:**
  - 미국 매크로, 한국 매크로(금통위, 수출입)
  - 실적: SK하이닉스, 마이크론, 엔비디아, 삼성전자, TSMC
  - 시장 구조: 옵션만기, 동시만기, MSCI, KOSPI200 변경
  - 휴장
- **한국장 반영일:**
  - 한국시간 15:30 전에 발표되면 그날 거래일
  - 15:30 이후면 다음 거래일 (휴장일은 건너뜀)
- **규칙으로 자동 생성:**
  - 옵션만기: 둘째 목요일 (휴장이면 앞당김), 3·6·9·12월은 동시만기
  - 주간 실업수당 청구
- **관리:** `data/events.yaml`. `estimated`(예상일)와 `confirmed`(확정)를 구분합니다. 일정은 연초에 1년치를 입력하고 수시로 확인합니다.

## 5. DART 공시 분석 (2~3단계)

```
DART OpenAPI (1~5분 주기) → ① 보고서명 규칙 분류 → ② 숫자 추출·강도 계산 → ③ LLM 맥락 해석
→ 공시 피드 / 알림 / E 영역에 반영 / 일정성 공시는 달력에 등록
```

| 방향 | 공시 유형 | 강도 기준 |
|---|---|---|
| 호재 경향 | 자사주 취득·소각, 공급계약, 실적 서프라이즈, 배당 증가, 내부자 매수, 무상증자 | 취득액/시가총액, 계약액/매출액 등 |
| 악재 경향 | 유상증자(주주배정·공모), CB·BW 발행, 대주주 매도·블록딜, 계약 해지, 실적 쇼크 | 희석률, 매도 지분율 |
| 치명적 악재 | 횡령·배임, 감사의견 비적정, 관리종목, 불성실공시 | 무조건 최대 악재 + 진입 금지 |
| 맥락에 따라 다름 | 제3자배정, 합병·물적분할, 시설투자, 교환사채 | LLM 해석 + 사람 확인 |

- **점수:** `방향 × 강도 × 유형 가중치 × 0.7^경과일`
  - 유형 가중치: 치명적 1.0 / 증자·CB·실적 0.8 / 대형 계약·소각 0.7 / 자사주·배당·내부자 0.5 / 기타 0.2~0.3
- **데이터:**
  - 공시검색 API, 주요사항보고서 API (구조화되어 있음), 원문 API, 재무 API
  - KRX KIND
- **검증:** 공시 유형별 이벤트 스터디. 공시 후 1~5일 동안의 시장 대비 누적 초과수익률(CAR)
- **한계:**
  - 초대형주에는 효과가 제한적
  - 이미 주가에 반영된 경우가 많음
  - 정정공시를 추적해야 함
  - 장중 공시는 몇 분 안에 반영됨
  - 원문 형식이 공시마다 다름
  - LLM은 오판할 수 있음

## 6. 수출입 데이터 분석 (2단계)

```
관세청·산업부 데이터 → 종목 연결(HS 코드 + 시·군·구 + 국가) → YoY·가속도·단가·분기 누적 → 신호
```

| 종목 예시 | HS 코드 | 지역 |
|---|---|---|
| SK하이닉스 | 8542.32 | 이천시, 청주시 (중국 공장 생산분은 통계에서 빠짐) |
| 라면 / 화장품 / 변압기 / 축전지 | 1902.30 / 3304 / 8504 / 8507 | 생산 지역 |

- **수출 점수:** `0.35×가속도 + 0.20×YoY + 0.20×단가 + 0.25×실적 추정 서프라이즈`
  - 세부 산식: `clip(가속도/15%p)`, `clip(YoY/30%)`, `clip(단가 변화/20%)`, `clip(추정 서프라이즈/10%)`
- **판단:** +0.5 이상 호재 / +0.2 이상 개선 / ±0.2 중립 / -0.2 이하 둔화 / -0.5 이하 악재
- **발표 일정:**
  - 10일 잠정치 (11일 전후), 20일 잠정치 (21일 전후)
  - 월간 동향 (다음 달 1일)
  - HS 10단위·시군구별 확정치 (다음 달 중순)
- **데이터:** 관세청 수출입무역통계, 공공데이터포털 API, K-stat
- **한계:**
  - 수출액과 매출은 다름 (해외 생산, 매출 인식 시점)
  - 시장이 이미 이 데이터를 보고 있음
  - 10일 잠정치는 조업일수 왜곡이 큼 (일평균으로 보정)
  - 지역 데이터에 여러 기업이 섞임
  - 기저효과
  - 조선처럼 한꺼번에 인도하는 업종에는 맞지 않음
- **검증:** 분기 누적 수출과 실제 매출의 상관관계(0.7 이상인 종목만 사용), 발표일 이벤트 스터디
